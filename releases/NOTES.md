# 简问 v1.0.0

轻量离线的 Android 问答自测应用，支持 Android 8.0 及以上版本。

- 题集新建、重命名、删除，题目添加、编辑、删除。
- UTF-8 JSON 单题集 / 全部导出，以及追加导入。
- 本地原子持久化，退出后题库不丢失。
- 逐字精确判题，实时准确率，随机轮次且同题不相邻重复。
- 自测进度与草稿恢复；单题题集作答后结束，避免相邻重复。
- 原生简洁界面，无广告、账户、联网权限或运行时第三方依赖。

安装 `simple-question-1.0.0.apk` 即可使用。APK 已签名，大小 37,952 字节。

SHA-256：`2c424a324897338cbbce9115e650ba6a154ef5dd96ed41265cb20b2d804e4d2e`

验证：21 项 JUnit 测试、Android Lint、Android 15 模拟器设备冒烟测试，以及签名 Release 安装与导入、判题验证均通过。

卸载或清除应用数据会删除本地题库，请定期导出 JSON 备份。签名私钥只保存在开发电脑，不包含在仓库或发布附件中。
